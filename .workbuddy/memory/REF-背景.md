用户三选：**整体移植 + 保留青色主题 + 真实值局部脱敏**。
第一版照搬原系统外壳被否 —— 导航重心错位、同一信息 4 处重复、三栏挤压中栏；现外壳见 `MEMORY.md` §1 / §5。

移植时泛化出来、仍然有效的规则：

- **动态页 id 含 `%`** → `$()` 抛 SyntaxError、该页永远打不开 → 用 ASCII 短哈希。
- `data-*` 设值必须**早于** `goto()`。
- **状态数字禁止硬编码**；**跨面板状态必须同源**。
- 追加 DOM 后要重算 `scrollTop`。
- **空分类不能静默跳过**（显式渲染空态）。
- 死代码断言不能只过滤规则起始行（`^\.wfcard` 会漏 `.wfcard__n`）。
