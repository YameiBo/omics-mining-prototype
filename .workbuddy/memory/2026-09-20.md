## 2026-09-20（续）· 移植后返工 v3：从「管理后台」改回「组学分析系统」

**根因诊断**（为什么"不像分析系统"）

3. 三栏 `246px 1fr 300px` 把中间挤窄，左栏工具名被截断。
4. 顶栏 7 个 tab 在 1280 宽下溢出。

**用户三选（AskUserQuestion 确认）**

**⚠️ 本轮踩到的坑（泛化规则）**
1. **左栏改分组后，原本挂在「工作流」列表头部的内置网络图入口失去归属** → 改挂到「工具库」首位（它本质是可视化工具），并为此新增 `[data-netgraph]` 断言。
2. **空分类不能静默跳过**：`TOOLCATS` 里「转录组分析」真实 0 个工具，原代码 `if(!items.length) return` 导致分类消失、被误当缺陷。改为**显式渲染空态** `<div class="tempty">暂无独立工具条目（相关能力见「流程模板」）</div>` + `data-empty="1"`，断言 `emptyCats` 明确列出。
3. **跨面板状态必须同源（旧版本的真实缺陷）**：编排区把 f09 硬编码成「运行中」，而运行历史显示「转录组 RNA-seq 4/4 已完成 + fastp 运行中」→ 两处矛盾。新增 `flowRunState(fid)` **回查 `HIST`** 派生徽章，并在智能体写入后补 `renderOrchList()` 做跨面板同步。断言 `flowRunning.consistent`。
4. **死代码清理的断言不能只过滤规则起始行**：`^\.wfcard` 只匹配规则头，`.wfcard__n` / `.wfcard__n .ico` 行漏网 → 断言假失败。按「整行含类名」过滤才彻底。清理时还要顺手删掉后置**覆盖块**（后置 `.wfcard__n{display:flex}` 其实是为旧列表写的，`.wfitem__n` 里只有文字不需要它）。
5. **`build.js` 的 `inlineIcons` 正则过严**：旧式 `/<i class="fa-solid fa-([a-z0-9-]+)([^"]*)"\s*><\/i>/g` 在 `<i>` 带额外属性（如 `aria-hidden="true"`）时匹配失败并**静默返回空串** → 图标消失但构建"通过"。改为匹配整个 `<i class="...">`、再正则抽取图标名；**抽不到就原样返回**，让自检把它抓出来。
