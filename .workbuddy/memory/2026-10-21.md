## 交接文档 + 路径可移植改造（v61 准备）

用户要求：「更新 handoff 文档，以方便我在别的地方能持续使用或更改这个 demo」。

**发现的问题**：`天中医体系管理智能体/HANDOFF.md` 存在，但那是**另一个子项目**（CNAS 迎检 Demo）。
组学原型这个 demo **没有自己的 handoff**；而且项目**没有 git**，
`build.js` / `verify.py` 里写死了 `/Users/yummy/...` 绝对路径 —— 这正是
「换个地方/换台机器就断」的第一道拦路石，光写文档解决不了。

### 改动 1：路径可移植（build.js + verify.py）

- `build.js`：`FA` / `TW_BIN` / `NM_TARGET` 三个写死路径 → 新增 `resolveNodeModules()`，
  解析顺序 `NODE_MODULES_DIR` → 从 ROOT 向上逐级找 `node_modules` →
  `~/.workbuddy/binaries/node/workspace/node_modules`；找不到就报错并给出安装命令，不静默失败。
- `verify.py`：`ROOT` 从写死路径改为 `os.path.dirname(os.path.abspath(__file__))`
  （`PROTOTYPE_ROOT` 可覆盖）；`CHROME` 改为 `_find_chrome()` 探测
  （`CHROME_BIN` → macOS/Chrome → macOS/Chromium → linux 三个路径）；
  `PORT` / `DL_DIR` 支持 `CDP_PORT` / `CDP_DL_DIR` 覆盖。

**结果**：整个 `prototype/` 目录可整体拷走，在新位置直接 `node build.js` 即可。
**产物零差异**：md5 仍是 `9015a282…`、体积仍 5,251,186 —— 纯工程改进，不动内容。
